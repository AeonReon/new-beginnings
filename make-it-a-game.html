Make It A Game

The jobs that turn into a fight — dressed, buckled, tidied, teeth — done laughing instead.

How to use this

Tap a square to jump to the moment you're stuck on, then open any game to see exactly what to say and do. Pick one, play it lightly, and swap it out the moment it stops being fun — a game only works while it's still a game. Each one carries the real reason the child digs in, so you can see what you're actually solving.

When no game lands

Some days a child is too tired, too hungry, or too far gone for play — and that's information, not defiance. Drop the game, stay kind, do the necessary bit with as little fuss as you can, and let it go. The game is a bridge, not a rule. If a whole routine is a fight most days, the answer is usually further back — sleep, hunger, or how much of you they've had — and that's what Turn It Around is for.
