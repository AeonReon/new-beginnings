# Philosophy

The thinking behind Conscious Parenting NI, the wider app pack, and Light School
— written down as it is worked out, because it is evolving in real time and it
governs every piece of copy in every one of these projects.

## How this folder works

```
philosophy/
├── README.md          ← you are here
├── 01-the-premise.md  ← why any of this exists
├── 02-not-homeschool.md
├── 03-isolation.md    ← the pitfall the whole project is built against
├── 04-excellence.md   ← thriving, not surviving — the positioning
├── 05-the-web.md      ← the pack: apps, resources, meet-ups, school
└── raw/               ← the brain dumps, VERBATIM and dated
```

**`raw/` is the source of truth for intent.** Those are the user's own words,
kept exactly as spoken, with nothing tidied away. The numbered files are the
worked-out version — if the two ever disagree, the raw dump wins and the
numbered file is wrong and needs rewriting.

Add a new dump as `raw/YYYY-MM-DD-short-slug.md` the moment it is said. Do not
paraphrase it into a numbered file and throw the original away; the phrasing is
half the value, and copy gets written straight out of these.

## The one rule that constrains all of it

Never a verdict on another family's choice. A parent whose child is in school
full-time is exactly as welcome, and copy that reads as a judgement on them is
wrong however true it feels. See `02-not-homeschool.md`.
